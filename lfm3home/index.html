LFM3 Home for Android

A local AI agent that runs Liquid AI's LFM3-1.7B on your phone. It reads and writes files, runs shell commands, searches the web, keeps a task list and long-term notes, and shows pages it builds in a preview pane. The model runs on the phone itself: chats and files stay on the device, and the only network traffic is the one-time model download and web searches the agent makes for you.

Install

  1. Tap Download the APK, then open the file when the download finishes.
  2. If Android asks, allow your browser to install unknown apps, go back and tap Install.
  3. Open LFM3 Home. The first launch downloads the model (1.1 GB, once; Wi-Fi recommended) and checks its SHA-256 before loading it. The status pill at the top shows the progress.
  4. When the pill says Ready, type a task. Commands and file writes ask before they run (Approvals: Ask); switch the chip to Auto to let the agent run them directly.

The same agent, tools and interface as LFM3 Home for Windows, with the phone's shell (sh) in place of PowerShell.

Requirements

  • Android 9 or newer, 64-bit ARM with the ARMv8.2 dot-product extension (most phones from 2019 on).
  • About 2.5 GB of free storage (the app plus the 1.1 GB model).
  • RAM sets the context window: 7 GB or more gets the model's full 262,144 tokens, 5 GB gets 131,072, 3.5 GB gets 65,536, less gets 32,768.
Preview build, tested as follows. On an Android 15 emulator (x86_64, 6 cores, 8 GB of RAM): a fresh install downloads and checks the model, loads the full 262,144-token context, and passes six agent tasks through the real interface (a web page with preview, a shell script written and run, a file edit, a file search, a web search and a memory note) at 8 to 13 tokens a second. The ARM build for phones has not yet been run on a physical device. It installs outside the Play Store, so your phone asks once to allow installs from your browser. Speed depends on the phone's processor; the model runs on the CPU.

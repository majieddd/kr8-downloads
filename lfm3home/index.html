LFM3 Home

A local AI agent that runs Liquid AI's LFM3 models on your own device. It reads and writes files, runs shell commands, searches the web, keeps a task list and long-term notes, and shows pages it builds in a preview pane. The models run on your PC's GPU or your phone's processor: chats and files stay on the device, and the only network traffic is the one-time model download, web searches the agent makes for you, and update checks.

Install on Windows

  1. Run LFM3-Home-0.3.0-x64-setup.exe. It installs for your user only, without administrator rights. The installer is not code-signed yet, so Windows SmartScreen may ask: choose More info, then Run anyway.
  2. Open LFM3 Home from the Start menu or the desktop. The first launch downloads the models and checks their SHA-256: 1.1 GB for LFM3, plus 1.6 GB for Omni in Team mode. The status pill at the top shows the progress.
  3. When the pill says Ready, type a task.

Use the models from other apps (Windows)

While LFM3 Home runs, other apps on the same PC can use both models through an OpenAI-compatible API, with no API key: LFM3 1.7B at http://127.0.0.1:8080/v1 and LFM3 Omni 2B at http://127.0.0.1:8081/v1. Hermes Agent, for example, can use them as custom providers. Closing the window keeps them running in the tray, and a watchdog starts a model again if it stops answering. The Server tab shows each model's state, a live log of every request, and switches to turn this off or to start LFM3 Home with Windows.

Install on Android

  1. Tap Download the APK, then open the file when the download finishes.
  2. If Android asks, allow your browser to install unknown apps, go back and tap Install. If you have 0.1.0, this installs over it and keeps your model and chats.
  3. Open LFM3 Home. The first launch downloads the model (1.1 GB, once; Wi-Fi recommended) and checks its SHA-256 before loading it.
  4. Later versions install from inside the app: tap Update, allow LFM3 Home to install apps the first time Android asks, then confirm Android's update dialog.

Requirements

  • Windows 10 or 11 (64-bit) with a GPU that has a Vulkan driver (NVIDIA, AMD or Intel), about 4 GB of free storage for the app and models, and 12 GB of GPU memory for Team mode at full context (one model needs about 5 GB).
  • Android 9 or newer, 64-bit ARM with the ARMv8.2 dot-product extension (most phones from 2019 on), about 2.5 GB of free storage. RAM sets the context window: 7 GB or more gets the full 262,144 tokens, 5 GB gets 131,072, 3.5 GB gets 65,536, less gets 32,768.

Preview builds, tested as follows. Windows (Windows 11, RTX 4080 Laptop, 12 GB): six agent tasks pass in Team mode and with LFM3 alone (Omni alone passes 2 of 6), the real window passes 8 of 8 checks in Team mode, the bundled Vulkan runtime runs LFM3 at about 100 tokens a second, and the Update button took a 0.1.9 install to 0.3.0 in under 7 seconds. Hermes Agent answered through both models, and a model server that was killed was answering again 8 seconds later. Not yet tested on AMD or Intel GPUs.

Android (Android 15 emulator, x86_64, 8 GB): six agent tasks pass at 8 to 13 tokens a second, and the in-app update went from 0.1.9 to 0.2.0 through Android's own update dialog with the model kept. The ARM build has not yet been run on a physical phone. Speed depends on the phone's processor; the model runs on the CPU.
